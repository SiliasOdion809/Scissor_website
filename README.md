# Scissors – URL Shortening Website

A responsive landing page for **Scissors**, a URL shortening and link management platform. This project is a frontend implementation based on the provided Figma design, built using HTML5 and CSS3.

## Project Overview

Scissors is a URL shortening platform concept designed to help individuals and businesses transform long URLs into shorter, more manageable links.

The website showcases the platform's services, pricing plans, features, and frequently asked questions through a clean and responsive user interface.

## Features

- **Responsive Navigation:** Navigation menu with links to different sections of the website.
- **Hero Section:** Introduction to the Scissors platform with call-to-action buttons.
- **Statistics Section:** Highlights platform statistics and usage figures.
- **Features Section:** Showcases URL shortening, custom URLs, QR codes, and data analytics.
- **Pricing Section:** Displays Basic, Professional, and Teams subscription plans.
- **URL Shortening Interface:** Frontend form layout for entering URLs, selecting domains, and specifying custom aliases.
- **FAQ Section:** Frequently asked questions with expandable answers using native HTML elements.
- **Call-to-Action Section:** Encourages visitors to get started.
- **Footer:** Includes company information, product links, resources, and social media references.

## Technologies Used

- **HTML5:** Used to structure the website and its content.
- **CSS3:** Used for styling, layouts, animations, and responsive design.

**Note:** This project was developed strictly with HTML and CSS, without JavaScript, in accordance with the assessment requirements.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash

```

### 2. Navigate into the Project Directory

```bash
cd scissors-website
```

### 3. Open the Website

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code to preview the website.
