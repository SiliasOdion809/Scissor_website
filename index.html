FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

You can try basic link shortening without an account. Creating an account unlocks link management, saved URLs and analytics.

Are the shortened links permanent? Will they expire?

Links remain active according to the service's retention policy and the settings on your account. A real deployment should clearly communicate its expiry policy.

Are there any limitations on the number of URLs I can shorten?

Limits depend on your plan. The Basic, Professional and Teams plans provide different usage allowances.

Can I customize the shortened URLs to reflect my brand or content?

Yes. Custom aliases and branded domains make links easier to recognize and share.

Can I track the performance of my shortened URLs?

Link analytics can help you understand clicks, scans, referrers and engagement over time.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

A production service should validate destination URLs, detect abuse, use HTTPS and provide a way to report suspicious links.

What is a QR code and what can it do?

A QR code is a scannable code that can open a URL on a mobile device, making it useful for print, events and in-person experiences.

Is there an API available for integrating the URL shortening service into my own application and website?

Yes, our API allows you to programmatically create and manage shortened URLs, as well as access analytics data.
